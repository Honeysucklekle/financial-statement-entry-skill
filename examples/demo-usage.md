# 使用示例与验收情形

## 三年一期录入

```text
请使用 financial-statement-entry，将本目录的审计报告和最新一期报表录入提供的模板。
保留原文件，分别生成合并与母公司输出副本。先确认实际期间、报告是否审计及金额单位。
主报表按元录入，右侧展示和分析表保留公式。各年度必须取对应年度报表的期末/本期数，不得用后一年期初数或比较数替代；缺少对应年度报表就标记缺失。
来源独立科目在模板没有行时，可在正确分类中作最小必要扩展，并同步小计、单位换算与分析表。
同步处理可获得的补充资料，记录缺失数据。重算并以来源中间小计和最终合计复核，提供映射与差异清单。
```

不要求两种口径时，只生成所需口径；来源未提供某种口径时，不用另一种口径替代。

## 固定结构录入

```text
请使用 financial-statement-entry 录入这份台账，不插行、不改公式和工作表结构。
有充分依据的同义映射或同类汇总可以使用并记录组成。
无法完整映射的非零项目另列差异清单，说明受影响的小计、指标和所需最小变更。
完成其余已确认录入并复核，不补“其他”、不硬写总计、不宣称未解决报表已全部勾稽通过。
```

## 年度取数与差异记录

```text
2024 年资产负债表只采用 2024 年报期末数，2025 年只采用 2025 年报期末数。
2025 年报期初数与 2024 年报期末数不一致时，保留 2024 年期末原值，另列差异和来源。
缺少 2024 年报时，不用 2025 年报期初数或比较数补齐，2024 年列标记缺失。
2025 年平均余额指标使用 2025 年期末与 2024 年期末；缺少后者则相关指标不可计算。
```

## 验收情形

以下金额是合成数据，用于检查处理行为，不能作为真实来源录入。

| 情形 | 应有结果 |
| --- | --- |
| 主表非流动负债有长期应付职工薪酬 120 万元，模板主表无行 | 新增正确分类的输入行，写入 1,200,000 元，非流动负债小计增加一次；负债结构展示 120 万元 |
| 来源应付债券 500 万元，其中优先股 100、永续债 50 | 父项录 500，明细可分别录 100、50，非流动负债只增加 500 万元 |
| 来源应收票据及应收账款合列 300 万元，附注拆分 80、220 | 分别录 800,000 和 2,200,000 元，合计 3,000,000 元，不另加一次合列金额 |
| 同一合列项没有附注拆分，用户固定结构 | 不猜拆、不各填 300；列出 300 万元未解决及影响，继续其他项目 |
| 来源信用减值损失以带符号金额 -10 万元列示 | 相加型损益行写 -100,000 元；若其他输入不变，营业利润减少 100,000 元 |
| 母公司无少数股东权益披露，模板预置 0 | 根据来源记录不适用/未披露，不将默认 0 当成已取数证据，不借用合并余额 |
| 最新一期为 2026 年 1-6 月，报表是累计值 | 输入区保留六个月累计金额，月份辅助结果为 6，仅适用周转率按 12/6 年化 |
| 缺少加权平均净资产，但指标公式显示 0 | 对应 ROE 不可计算，不能用期末净资产替代，也不能宣称真实收益率为 0 |
| 插入利润表新主科目后，原净利润行号变化 | 盈利能力固定引用、万元展示、补充资料与主要指标均指向正确的新位置，不以无 `#REF!` 作为唯一证明 |
| 来源每股收益 0.50 元/股 | 主录入和右侧展示均为 0.50 元/股，不转换为万元 |
| 资产和负债输入都缺失，但平衡差额公式等于 0 | 覆盖状态不足，不能报告资产负债表已核对通过 |
| 其他综合收益有两组 20、30 万元，而模板总额默认 0 | 录入并核对总额 50 万元，综合收益总额比净利润增加 500,000 元；父项与明细不重复累计 |
| 2025 年度的相邻列是 2023 年末 | 不能作为 2025 年初计算平均余额，取得 2024 年报期末数，否则将相关指标标为不可计算 |
| 最新一期仅为 2026 年 4-6 月 | 期间为 3 个月，不能直接采用表头辅助公式返回的截止月份 6 |
| 仅要求补录最新一期现金流量 | 只改本次输入及受影响公式，不清空未更新的历史列、利润表和资产负债表 |
| 来源显示比率 20% | 对应底层 0.20 与百分比格式，不能写 20 后显示成 2000% |
| 2024 年报期末资产 1000 万元，2025 年报期初资产 1100 万元 | 2024 年列保留 1000 万元，另记 100 万元差异，不用 1100 万元覆盖 |
| 仅有 2025 年报及其 2024 年比较数，没有 2024 年报 | 2024 年列标记缺失，不回填比较数；需要 2024 年期末余额的指标不可计算 |

最终交付说明：输出文件、期间与口径、来源单位及各年度取数来源、另列的重述差异、新增或汇总项目、受影响公式、重算及来源校验结果、未解决项与不可计算指标。
