# 模板缺失科目的处理

目标是完整保留来源的经济含义，并使主报表、单位展示和分析表一同正确计算。不能漏掉非零项目，不能把所有新科目塞进“其他”，不能通过覆盖合计来掩盖缺口。

## 先判断缺失的类型

| 情形 | 处理 | 必须留下的依据 |
| --- | --- | --- |
| 名称不同、含义和层级一致 | 映射到原有行，保留模板标签 | 原标签、目标标签、来源页码、同义依据 |
| 来源分列，模板一个汇总输入行 | 目标明确是这些同类项目的汇总时可汇总，逐项保留金额 | 同期间/口径、全部组成、求和关系、其中明细及总额/净额要求 |
| 来源合列，模板分列 | 优先从同期间、同口径附注获得拆分 | 拆分来源以及拆分和等于原合列的复核 |
| 父项下的“其中”披露 | 父项录全额，明细单独记录或录入对应其中行 | 父子关系，注明不再次进合计 |
| 独立主项目，没有合理映射 | 在输出副本相应分类内新增独立行 | 分类、来源名称、期间金额和受影响公式 |
| 明确零或不适用且无需单列 | 可不新增行，记录状态和依据 | 确认来源是零/不适用，不是未披露 |
| 拆分、分类或来源不清 | 记为未解决，继续其他项目 | 原额、争议点、待补充资料及受影响合计 |

规范空格、编号或全半角后仍不确定的名称不能靠模糊相似度自动匹配。例如“合同资产”不等于“应收账款”，“应收款项融资”不等于“应收票据”，“合同负债”不等于“预收款项”；须有来源证据才能重分类。旧准则与新准则列示差异也不能按近似名称强行搬移。

同类汇总不能改变原本需要区分的总额、净额、流动/非流动、业务活动或收益费用列示。不能把应收与应付、收入与成本抵销后塞入一个现有行；小金额也不是省略来源独立非零项目的依据。

来源“应收票据及应收账款”合列而模板分列时，不能各填一次全额，也不能按比例猜拆。附注明确分拆则分别录入；没有分拆依据时可在允许扩展的副本新增合列项，替代参与汇总的分列输入，明确分列明细未知，受影响周转率不可计算。固定结构且不允许合列替代时保留未解决，不择一行塞入全额。

## 默认扩展规则

普通“把来源报表录入模板”的任务允许为完整录入做最小必要扩展，但只修改输出副本。若用户明确禁止插行、修改公式或结构，先遵守限制；有充分依据的同义映射、同类汇总可继续，其他项目另列差异清单并说明需要的最小结构变更。

1. **跨期间一起设计**：先收集本次各期间所有新科目，在同一口径工作簿内采用统一的行结构。不同年度未披露的金额不补 0，不移用其他年度余额。
2. **在正确层级添加**：独立科目放在相关分类小计之前；其中明细放在父项之后且不独立进小计。只有位于正确分类内、确为预留输入行、已被相关汇总和展示覆盖的空行可复用。工作表末尾空白行不等于有效预留行。
3. **复制相邻同类样式**：复制必要的字体、边框、数值格式、对齐、行高及左右对应区域。不得从合计行复制错误的金额公式作为新输入。
4. **更新汇总表达式**：显式确认新增主项目进入一次正确的小计、收入/成本/损益/现金流关系。检查 `SUM` 的插行边界、非连续参数、抵减和其中项排除，不假设插行工具会自动扩范围。
5. **更新所有依赖**：检查单位换算区、固定地址引用、`INDEX/MATCH` 的两段范围、命名区域、分析表、财务指标、校验、条件格式及打印区域。仅移动行号、使用公式平移工具或改本表 `SUM` 都不足以证明跨表引用正确。
6. **分析表覆盖完整**：对应结构表已有该科目时绑定到新行；没有时按原分析表样式添加必要展示行，并检查分类小计和占比。利润和现金流新增独立项目也应在相关展示中可追溯。无须进入某指标的项目不能为“全部联动”机械加入所有算式。
7. **重算并验证**：用来源小计作独立控制，对新增行输入一个临时非零样例，确认上层总计、单位展示和受影响指标各变化一次，父项明细不重复变化。检查各期间，恢复全部临时输入，再录入并核对真实数据。

不得直接覆盖总计或把“来源总额减已录明细”写入“其他”补平。来源本来披露“其他”或其附注明确属于该行的项目可以录入/汇总，但要记录依据及组成。

## 本模板的典型情形

- **长期应付职工薪酬**：主资产负债表无此行，负债结构已有名称查找。若来源独立披露，在非流动负债小计之前新增，更新左右区及相关范围，确认“负债结构”不再因查找失败显示 0。
- **可供出售金融资产**：来源仍按旧准则独立列示时，在非流动资产中保留原名，不无依据拆成债权投资和其他权益工具投资。绑定资产结构已有展示行。
- **应付短期债券**：如来源独立列示且没有包含在已录父项中，在流动负债中新增。模板全部债务已有此名称查找，检查它被计入一次；若另列明细已包含于其他主项目，先防止总债务重复。
- **汇兑净收益**：只有来源将其作为独立损益项目且未包括在财务费用等父项中时，新增主利润表行，更新营业利润公式和盈利能力展示。若仅是财务费用附注明细，不在营业利润中再次相加。
- **金融企业专用收入、成本及资产负债**：通用模板可能缺少利息净收入、手续费收入或专用资产/负债。先确认来源列示是毛额、净额、主项或其中项，再扩展所属合计与分析。模板适配需要较大行业重构时，交付已明确项目与适配清单，不把通用公式称为已完整适用。

## 完整性复核

按口径和期间比较来源独立主项目与目标映射，确保每项都有去向。来源分类合计与目标分类合计分别比较，查证抵减及父子包含关系。未解决记录须包含：原项目、金额、期间、原因、影响的总计/指标和所需资料。金额相等只是必要检查之一，不能替代分类和来源覆盖检查。
