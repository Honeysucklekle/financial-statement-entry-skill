# 随附模板说明

适用于仓库 `template/financial-statement-template.xlsx`，2026-10-06 替换的 12 表版本。坐标仅作初始定位，扩展或使用其他模板后必须重新读取。

## 布局和单位

| 工作表 | 主录入区或作用 | 关联区域 |
| --- | --- | --- |
| 基本信息 | B1:E1 期间；B2:E4 审计信息 | 初始 B1 为“最新一期”，C1:E1 为“20xx年” |
| 资产负债表 | A 列项目、B:E 金额（元） | H 列标签、I:L 公式展示（万元） |
| 利润表 | A 列项目、B:E 金额（元） | G 列标签、H:K 公式展示（万元） |
| 现金流量表 | A 列项目、B:E 金额（元） | G 列标签、H:K 公式展示（万元） |
| 补充资料表 | A 列项目、B:E 金额（元） | G 列标签、H:K 公式展示（万元） |
| 主要财务指标 | 公式计算金额（亿元）、比率等 | 从主报表、补充资料和运营能力取数 |
| 资产结构、负债结构 | 金额（万元）及构成比例 | 多数使用精确名称 INDEX/MATCH |
| 盈利能力、现金流量 | 展示金额（万元） | 多数直接引用主表固定单元格 |
| 偿债能力、运营能力 | 财务比率及周转天数 | 运营能力 H2 是最新一期月份辅助公式 |

“基本信息”是期间表头的共同来源。常用布局为 B 最新一期、C 最近年度、D 次近年度、E 最早年度，但年份仍以任务和来源为准。两侧区域是同一口径的单位转换，不能左填合并、右填母公司。

最新一期表头可以采用明确日期或能识别月份的文本，例如“2026年1-6月”。须核对 `运营能力!H2` 实际返回 6，且月份为 1 到 12 的整数，而非仅凭表头外观判断。列示全年时也检查返回 12。裸数字年份可能被公式当作 Excel 日期序号，不用数字 2026 表示最新一期全年。模板采用 360 天计算周转天数，最新一期周转率采用 12/月份数年化；不把三大报表输入金额年化。

## 需要特别检查的依赖

1. **名称查找**：资产/负债结构及主要指标存在精确 `MATCH`，部分键保留空格和完整说明。辅助匹配可以规范名称，不能直接改模板标签。新增空值保护也必须使用原查找键，而非未经核对的分析页显示标签；后者可能与主表的总计名称不同。插行后同时检查查找的标签列与金额列长度、顺序一致，范围包含新增行。
2. **固定地址**：盈利能力、现金流量以及补充资料利息等直接引用主表地址。仅复制单元格公式或只改当前表，不保证其他工作表同步。重读全工作簿的相关引用。
3. **可选科目查找**：资产结构有“可供出售金融资产”、负债结构有“长期应付职工薪酬”、盈利能力有“汇兑净收益”、全部债务公式有“应付短期债券”的查找，但主录入表尚无这些行。来源出现这些项目时必须按缺失科目规则处理；查找失败显示 0 不能证明项目不存在。
4. **同名其中项**：负债结构的优先股、永续债查找有同名多处，不能假设全表第一处匹配正确。应付债券与其他权益工具的明细须按父项范围定位。
5. **缺失值掩盖**：大量指标使用 `IFERROR(...,0)`，空模板显示 0 不表示有来源数据。检查实际依赖；在输出副本中对受影响指标使用明确的不可计算状态，不能仅扫描 Excel 错误值。金额保护不用于文字表头；修正后检查所有期间标题、结构表总计金额与 100% 总计占比，防止有效内容被保护条件隐藏。
6. **占位和默认值**：“主要财务指标”第 28 行是占位项，公式为 0。利润表和少数股东权益有默认 0。保留模板原文件，在录入副本中根据真实披露与缺失状态处理，不将占位值作为披露。
7. **非金额项目**：利润表每股收益右侧直接引用主录入原值，例如 `H47=B47`。保留来源的元/股单位，不能用金额行的万元换算公式向下覆盖这些行。
8. **指标口径**：全部债务按模板所列项目计算，可能不覆盖某企业的全部有息债务。新增行业负债时检查是否应计入该指标；口径无法判断时列明限制，不默认为零或擅自改变债务定义。
9. **最早年度及期初**：运营能力 E 列周转率初始为空，缺少前一年期末余额时保持不可计算。不能以期末值冒充平均余额，或将最新一期与不对应的前期列相平均。各年度余额必须来自对应年度报表期末数，不用后一年期初数替代；后续重述差异单独说明。

本版本按用户提供文件原样入库；以上事项是录入输出副本时的检查规则，不能把空模板的旧缓存或零值称为完整的数值验证。

## 本轮补充的使用边界

- `利润表!B32:E44` 的其他综合收益总额、两类分组和各明细是输入而非自动汇总，必须按来源分别填写及核对。只填末级明细不能改变总额默认 0 或综合收益公式结果。
- 运营能力默认以相邻列的期末余额构成平均余额，并从最新一期表头识别截止月份。跳年、非自然年度和只提供单季度时不能沿用这一默认逻辑。
- `主要财务指标!B20` 最新一期平均总资产回报率和 B21:B22 的 ROE 现有公式没有乘 12/月数。记录其期间口径，来源明确年化或任务需要年化时再在副本作必要调整；年化规则不同的指标不能直接视作同口径。
