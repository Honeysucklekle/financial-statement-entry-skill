# 完整性与勾稽复核

数值算对、来源映射完整和展示结果可用是三项不同检查。以下规则用于输出副本，不改变仓库提供的原模板。

## 输入状态与依赖

每个必需来源项目在映射记录中保留状态，不只保留金额：

| 状态 | 数值处理 | 是否可参与已完成的计算 |
| --- | --- | --- |
| 已取数 | 写入已复核数字，包括合法负值 | 可以 |
| 明确零 | 写入数字 0，保留零值依据 | 可以 |
| 不适用 | 按既有展示习惯留空或“-”，记录范围 | 该项无需时可以；必需分母不适用时指标不计算 |
| 缺失 | 留空，不把旧值或默认 0 当作新来源 | 相关必需依赖不完整 |
| 待核实 | 原始 OCR/冲突值另记，未经确认不作正式输入 | 相关必需依赖不完整 |

模板没有列示某个普通企业根本不存在的行业项目，不代表该企业报表不完整；但单凭空格、查找失败或报表平衡，也不能证明该科目不存在。

不在数字输入格混填“缺失”，使加减公式产生错误。状态优先保存在独立映射/复核记录或模板已有说明区；不为几项状态默认重建工作簿。

保留正确的计算路径，并对受影响输出最小修改：例如必需数据尚未取得时，用有依据的输入完整性条件使相应指标显示空白/不可计算，附简明原因；数据确认后原计算公式仍能恢复。若必须增加辅助状态位置，使用既有空间或独立记录，在任务允许的范围内最小扩展，不增加与其他完整结果无关的全局阻断。固定公式任务无法增加保护时，另列对应单元格和“此显示值不可使用”的原因。

`COUNT`/`ISNUMBER` 只能判断数字是否存在，不证明它来自本次正确报告。已声明不适用的可选项不应阻断其他计算，来源已确认的真实 0 也不应当作缺失。

### 空值保护的范围与回归检查

- 先区分金额、比率与文字链接。`ISNUMBER` 适用于必需数字依赖，不能包住期间标题、审计机构等文字链接，否则有效表头也会变空白。
- 查找型公式的保护须沿用原公式的查找键、父项范围和匹配方式。分析页显示的“资产总计”与主表带空格的“资  产  总  计”可能不同；不能直接拿显示标签判断匹配是否存在，再将原本有效的查找阻断。仅找到名称也不足以证明对应金额已取得，继续检查源金额与状态。
- 只保护有缺失风险的计算，保留原计算路径。不用统一的错误回退掩盖公式故障，也不因一项补充资料缺失而阻断三大报表的其他完整结果。
- 修改后分别验证真实数字、明确零、缺失和文字标题。检查关键汇总金额及分类占比分母；有来源且分母有效时，资产结构和负债结构的总计占比应为 100%。所有明细占比均为 0 或空白时，先追踪总计查找和保护条件。

## 先做单元格复核，再做勾稽

每完成一个口径，先回看原报告，检查科目、列、期间和口径，再检查公式汇总。两轮复核不能互相替代。

单元格复核重点：

- 同名科目有没有写到另一年份、另一口径；原稿空格有没有串入邻行数值或比较列的 0。本期空白而上期明确为 0 时，本期仍记为未列示，不将上期 0 当作本期已确认数字。
- 扫描件续页有没有重复或漏掉行；报表标题、单位、表头是否与映射记录一致。
- 应付票据、应交税费、其他应付款、资产处置收益、汇率变动对现金的影响、少数股东权益逐项回看，这些容易错行、变号或串口径；其他 OCR 不清晰项也需回看。
- 补充资料中的当期折旧、无形资产摊销、长期待摊费用摊销有没有取自对应年度附注并写到正确年份列，不跨年借用。
- 自动写入是否避开原有公式；写入金额、符号、空白处理是否与已确认映射一致。只验证程序运行成功不算来源复核。

勾稽出现差异时按层级定位：

| 报表 | 至少对照来源的汇总 | 追溯顺序 |
| --- | --- | --- |
| 资产负债表 | 流动/非流动资产、资产总计，流动/非流动负债、负债合计，归母权益、少数股东权益、权益合计、负债权益总计；不适用项目单独标记 | 总计 → 差异分类 → 分类内明细，再检查净额及其中项 |
| 利润表 | 营业利润、利润总额、净利润、其他综合收益和综合收益总额 | 收入/成本与费用 → 其他、投资、公允价值、信用/资产减值、资产处置等损益 → 营业外收支与所得税；结合符号和来源小计查找首次偏差 |
| 现金流量表 | 三类活动的流入/流出小计与净额、现金净增加额、期末现金余额 | 三类净额 → 汇率影响 → 期初现金 → 各类流入流出明细 |

定位已证实的原因后，只修正相应输入或引用并重算，不大面积重录，不改总计补平。第一次发现的差异不一定是唯一错误，继续核对其余小计与明细，避免漏项和重复项相抵销。

## 独立的来源对照

每个关键汇总保留一条简明复核记录：

```text
口径｜期间｜项目｜来源文件/页码｜来源原值/单位｜换算后的来源值
｜Excel位置｜重算结果｜差额｜容差｜输入覆盖状态｜通过/待核实/不适用｜原因
```

差额采用同一单位的“Excel 重算结果减来源披露值”。不能把 Excel 公式总计抄一份作为来源对照，也不能只比较两个依赖同一错误输入的模板格。

必需明细不完整时，即使来源总计已经取到、差额恰为 0，仍标明覆盖不足。分类错误互相抵销、漏项与重复项金额相等，都会造成假通过。来源本身存在加总差异时如实记录，不增加人为平衡项。

容差须与来源精度及核对对象匹配。显示两位小数的万元来源，最小显示步长为 0.01 万元即 100 元。某项独立舍入可能产生半步长误差，多个已舍入明细再加总的累积误差须按项数及原披露方式分析，不对所有合计一律套 50 元或统一放宽阈值。记录舍入原因，不把精确来源的错录当舍入。

## 分层及跨表核对

- 每个父项只包括应包含的明细；“其中”只作披露，不重复相加。来源汇总有但明细不完整时，可填模板的输入型汇总并标注明细缺失，不为补齐明细倒推任意分配。
- 本模板其他综合收益 32、33、38 行为输入，未自动汇总明细。来源充分披露时，检查 33 行等于 34:37 行之和、38 行等于 39:44 行之和、32 行等于两组之和，再检查净利润加其他综合收益等于综合收益总额。来源新增其他综合收益明细时扩展对应组；来源只披露总额时录总额并说明未披露明细，不宣称分组已核对。
- 资产负债表的未分配利润与利润表净利润不能直接画等号；检查所有者权益变动表或附注中的期初、损益、分红、资本变动、其他综合收益和调整。只在来源提供足够信息时做这项桥接。本年报表期初数可用于解释期初调整或桥接差异，但不得用来回填上年度期末列。
- 现金流量附注提供净利润调节至经营净现金流时，可作辅助独立核对。缺少调节资料不凭收入/利润推算现金流。现金流量表自身的本期现金期初数按该表披露录入，用于本期现金勾稽，不将其作为上年度资产负债表期末数的替代来源。
- 科目缺失并不总在主表体现。新增其中明细可能影响债务构成、利息或专用分析，但不应再改变包含它的上层主表合计。

### 跨期现金余额与受限资金

分别保留本期现金流量表的期初/期末现金及现金等价物、上一期原现金流量表期末余额、对应资产负债表货币资金，以及附注的受限资金和现金等价物定义。先核对日期、主体、单位及报告版本，再比较差异；不能把这些金额当成同一个项目。

本期期初现金与上期原现金期末数不同，或现金余额恰好等于货币资金但附注披露受限资金时，追查重述、合并范围变化及现金定义说明。金额相等或差额等于受限资金都只是线索；受限性质和现金等价物范围有充分依据后才能解释，不能机械扣减全部受限资金或断言来源有错。

正式录入保留已确认报表列示的现金余额；无充分解释的差异单独列为待核实，不改期初现金、不借本年期初数回填历史列、不修改现金净增加额补平。本期现金表内部勾稽一致与跨期现金口径已确认分别报告。

## 指标的日期、归属和展示

- 使用平均余额时，核对其真正的期初/期末日期。2025 年度须用 2025 年报期末数与 2024 年报期末数；相邻列为 2023 年末时不能替代 2024 年末，也不能用 2025 年报期初数回填。最新一期的年初余额同样取上一年度报表期末数。缺少对应年度报表则相关指标不可计算。
- 后续报告的重述或合并范围变化不改变上述取数规则。必需数字齐备且用户已指定原年度来源时，照常计算并说明可比性限制；不能因为比较数经过调整就自动显示不可计算，也不能为消除差异换用本年报告的调整后期初数。必要的辅助状态分别说明“期初来源可取得”与“跨期口径可比”，不得让一个可比性勾选框擅自改变用户指定的计算。
- 季度或非自然年度要记录实际起讫日和期间长度。“2026年4-6月”覆盖 3 个月，不是 6 个月；模板仅识别截止月份的公式不足以确定覆盖月数。必要时仅在输出副本修正该辅助公式，或使用已确认的期间长度。
- 先说明指标是否年化。模板最新一期周转率默认年化，最新一期平均总资产回报率和 ROE 的现有公式不自动年化；不能因表头为最新一期就把全部指标年化，也不能将不同处理的指标直接比较。
- 归母、全部净利润、扣非及普通股股东口径与相应净资产定义配对。源报告存在优先股、永续工具等时核实相关口径调整。母公司报表未列合并归属项目时，不能从合并表补值或把“不适用”显示为真实 0。
- 负净资产、为零的利息支出或为零的平均余额不是一般的有效分母。区分数学上不可计算、业务上不适用与按任务要求披露但需说明的负比率，不用 `IFERROR(...,0)` 隐去。
- 百分比按底层小数与单元格格式成对检查。20% 对应 0.20 配百分比格式；不得把 20 再配百分比格式显示成 2000%，或把小数直接套普通数值格式冒充百分数。金额的元/万元/亿元另行转换。

## 保存与交付

重新打开输出文件，确认本次指定区域正确，未更新的历史列、公式和样式没有被意外清理。必要时比较编辑前后的数值与公式清单，不把文件哈希不同当作定位方法。

针对插行或依赖修改，复核实际保存后的引用和计算结果。检查明细新增金额正好进入一次正确汇总；检查其中明细不改变已含它的父项；检查来源分类合计与分析分类合计相符。零输入样例不能证明新增行被纳入公式。

区分四种交付状态：报表已录入且已核对、已录入但需核实差异、仅部分录入、分析指标因资料不足不可计算。按具体期间/表/指标说明，不给不完整工作簿一个笼统的“通过”。
