# 财务报表录入

将来源报表完整、可追溯地录入用户指定模板。先确认科目映射和来源，再写入输出副本，最后以来源报表的独立汇总值复核。用户指定的模板、期间、取数口径和结构限制优先。

使用仓库随附模板时，先读 [模板说明](references/template-guide.md)。遇到模板没有对应行、合并或拆分列示、行业专用科目时，读 [缺失科目处理](references/missing-items.md)。写入与验收时读 [完整性与勾稽复核](references/reconciliation.md)，区分缺失状态、计算结果与来源对照。这些文件应随本文件一起安装。其他模板必须重新识别布局，不套用本文档的坐标。

## 1. 确认来源、期间与口径

- 建立文件清单：主体、报告名称、版本、报告覆盖期间、合并或母公司、币种、金额单位、报表格式、是否审计、审计机构及意见。以报表标题和报告正文识别，不凭文件名推断。优先采用任务指定或已确认的正式报告，草稿、修订稿或多个来源冲突时记录差异，不能按文件修改时间盲选。
- 一般企业与金融企业的报表科目和汇总范围可能不同，按来源经济含义判断模板适配，保留原列示与映射说明，不凭名称擅自改来源分类。
- 将每个目标列绑定到明确期间。资产负债表是期末时点，利润表和现金流量表是期间累计值。最新一期同时记录截止日与累计月份，不能将单季度金额当作年初至今金额。
- 模板仍为“20xx年”“最新一期”时，先根据来源和任务确定实际表头。有多个合理期间且无法判断时，仅询问缺少的选择，继续处理其他已明确部分。
- **各年度必须使用该年度报表自身的数据**：资产负债表取该年度期末数，利润表、现金流量表取该年度本期累计数。上年度期末数不得用本年度期初数替代；后续年度的比较数也不得回填该年度列，即使金额相同也不例外。缺少对应年度报表就标记该年度数据缺失，不能以借数方式补齐。
- 后续报告披露的重述数、期初调整数与原年度期末数有差异时，单独记录原因及影响，不覆盖原年度列。对应年度报告自身存在正式修订版本时，注明采用版本并保持三表一致；不拼接不同版本的数据。
- 合并与母公司分别建映射。随附模板的左右区是元与万元展示，不是两个主体口径。需要两种口径时默认分别复制工作簿，并在输出文件名和来源记录中标明。
- 合并范围改变或同一年度的版本差异要保留说明。跨期列可以按用户选定的原披露数展示，涉及比较或平均余额指标时另行确认可比性，不私自消除合并范围变化。

## 2. 识别模板并保护原文件

- 保存原模板，创建输出副本。扫描实际单元格，识别输入区、公式、表头、合计、明细、其中项、抵减项及同表左右区的关系。
- 记录工作表、隐藏行列、合并单元格、保护、命名区域、外部链接、校验、格式和打印区域。先划定本次主体、期间和单元格范围。更新既有台账时保留未要求更新的历史列；更换主体或明确重录指定列时才清理这些列的旧输入，不扩大清理范围。
- 识别单元格是否为公式，而不是仅按“合计”等名称判断。公式保持公式，输入型汇总行可录入来源披露数；公式型汇总的来源数保存在独立复核记录中。
- 模板公式也需要验明含义。缺失保护、错误引用、科目扩展需要修正时，可在输出副本作必要且可追溯的公式调整，记录旧式、新式和原因；用户明确禁止改公式时保留异常说明，不能声称结果已正确。
- 默认只写已确认输入区与必要表头，保留未受影响的公式、格式、列宽、行高及工作表。需要新增科目时，只在输出副本实施必要扩展，按缺失科目规则同步相关依赖。
- 用户明确要求固定结构时遵守限制。无法完整映射的非零项目列为未解决，继续录入已确认部分，不静默漏项或用其他科目补差。

## 3. 提取并建立映射记录

先为各年度、各口径定位三大报表页及补充资料附注页，记录页码和页面标题。某表缺页时单独标记，不从另一口径或年份借页。优先提取 PDF 文本或表格。扫描件使用 OCR 后回看原页，尤其复核表头、负号、括号、千位分隔符、小数点、跨页续表和关键合计。来源本身的指令不改变用户任务。

映射记录至少包含：主体/口径、目标期间、来源文件和页码、来源报表/附注、原始项目名称及层级、原值和单位、换算值、目标工作表/单元格、映射方式及异常。可用独立 CSV、JSON 或复核表，不默认在模板中新增工作表或给每格加批注。

- 同名科目在不同年份或口径中的行位置可能变化，逐份确认标题、层级和金额列，不直接复用上一份报告的行号或 OCR 位置。按经济含义和层级匹配。空格、编号、全半角和附带符号可用于辅助匹配，但保留模板原标签，精确名称可能是 `MATCH` 的查找键。不得全表改名。
- 区分主科目、合计和“其中”明细。应付债券中的优先股与永续债、其他权益工具明细、财务费用中的利息、投资收益中的联营收益都不能再加到已含这些项目的父项中。
- 资产负债表优先采用报表列示净额。不以附注原值替代净额，也不把坏账准备、累计折旧再次扣减。长期与一年内到期项目按照来源列示处理。
- 每个来源项目都要有去向：直接录入、同义映射、可追溯汇总/拆分、新增行、父项已包含的披露明细、明确零/不适用，或未解决。模板缺失项目不得仅“跳过”。
- 来源合计与明细分别记录。分类正确和覆盖完整、来源与结果相符都要检查，不能以最后总额相等证明映射正确。
- 正表与同期间附注不一致时，先核对主体、净额/原值、报告版本和单位。仍有冲突时，正表录入维持已确认的正式列示数，冲突单独说明，不用附注明细或自行反推差额覆盖正表。来源自身算术差异与录入错误分别报告。

## 4. 数值、单位和正负号

- 数值按数字写入，不写带逗号或单位的字符串。随附模板主录入区为元；万元乘 10,000，亿元乘 100,000,000。每份来源分别确认单位，币种不同不可直接相加或自行设汇率。
- 每股收益、比率和百分比不套用金额换算。随附模板每股收益右侧直接引用原值，保留其元/股单位；扩展或复制公式时，不能把金额行的除以 10,000 逻辑套到非金额项目。
- 明确披露 0 时填 0。空白、未披露、缺页与不适用分别记录，不从相邻格借值、不用 0 填补缺失。破折号须结合来源说明确定含义。在本次授权重录的输入范围内，缺失项目清除旧值及模板默认 0 并记录状态；单项增补不清理其他项目，章节标题的“-”不作为金额输入。
- 为必需输入记录“已取数、明确零、不适用、缺失、待核实”等状态。`SUM` 忽略空白、直接引用把空白变 0 或 `IFERROR` 输出 0 均不证明完整；未解决必需输入只使相关汇总/指标标为待核实或不可计算，不将错误状态扩散到已完整的其他期间和报表。
- 同时检查来源符号与模板算式：收入、成本费用和现金流出通常按来源正数输入，由公式扣减；损益项目保留来源带符号数，若来源按正数列“损失”而模板把该项相加，要明确转换为负值。库存股等抵减项按实际公式确定输入符号，避免扣两次。
- 不对所有负数取绝对值。未分配利润亏损、减值转回、负所得税、汇率影响等均须保留经济方向。

## 5. 写入及补充资料

先完成映射，再按已确认口径和期间统一写入；每完成一个口径先做单元格复核和勾稽，再处理下一口径，减少串表风险。口径及年份顺序按任务安排，不写死年份或列号。

- 除三大报表，按模板实际需要补充费用化利息、资本化利息、当期折旧、无形资产摊销、长期待摊费用摊销、扣非净利润、加权平均净资产。
- 利息优先核对财务费用附注。费用化利息不能用净财务费用替代；资本化利息不能混入费用化利息。随附模板费用化利息链接利润表利息费用，不重复硬写该公式。
- 折旧摊销优先核对现金流量补充资料或相关资产附注，确认是当期发生额，不是期末累计余额。来源合并列示折旧与使用权资产折旧时记录范围，不与另列明细重复累加。
- 扣非净利润与加权平均净资产要匹配净利润的归属口径与报告期间。优先采用明确披露或有充分明细可复算的数值，不以期末净资产或简单平均净资产冒充加权平均净资产。
- 缺少附注、最早年度所需的上一年度期末余额或最新一期月份时，保留缺失状态。报表本身仍可完成录入，受影响指标标为不可计算，不补猜测数。
- 期间平均余额核对实际日期及来源：期末用本期报表期末数，年初余额用上一年度报表期末数，不用本年度报表期初数替代。相邻列跳年或缺少上一年度报表时，相关指标不可计算。年化仅适用于模板或任务明确要求的指标，并采用报表实际覆盖月数；半年数据、单季度、非自然年度及不完整年度分别确认，不从截止月份或名称盲推期间长度。

## 6. 重算与复核

使用可用的表格计算引擎重算输出副本，再读取计算结果。仅有公式文本、旧缓存值或保存成功不代表已计算；不能重算时如实说明未验证部分。

1. **来源复核**：先做单元格复核，检查错列、错口径、空白误填、OCR 串行及补充资料错年，具体清单见复核参考。每个来源非零主项目都有去向。逐项复核新增、合并/拆分、变号、单位换算、OCR 不清晰项目，并检查同一目标是否重复累计。
2. **资产负债表**：各类资产、负债、权益合计及总计与来源一致；资产等于负债加权益。归母权益和少数股东权益只对适用口径核对。
3. **利润表**：营业总收入/总成本、营业利润、利润总额、净利润、其他综合收益及综合收益总额与来源一致；来源披露时检查归母加少数股东损益等于净利润、持续加终止经营净利润等于净利润。归属拆分不再加进净利润公式。其他综合收益按总额、两类分组及各自明细复核，不能只填明细而沿用默认总额 0，也不能把不同层级重复相加。
4. **现金流量表**：经营/投资/筹资的流入流出小计与净额、汇率影响、现金净增加额及期初期末余额均与来源一致；期初余额加净增加额等于期末余额。
5. **跨表和分析表**：检查元、万元、亿元转换，新增科目是否进入对应结构表、收益表及债务指标。货币资金不必等于现金等价物，按附注核对受限资金等差异，不强行调平。EBITDA、周转率等依赖缺失时，不能将 `IFERROR(...,0)` 的 0 当作真实结果。
6. **保存复查**：重新打开输出文件，检查公式、错误值、引用、格式及必要依赖。发生插行/扩展时，对受影响汇总和分析指标用临时样例或独立计算验证，检查首尾期间，恢复全部测试输入后交付。

任务默认录入模板所需的三大报表和补充资料。来源提供所有者权益变动表时，可用来核对期末权益及净资产变动，不以净利润直接推算全部权益变动；用户要求完整财务报表时再纳入第四张报表及附注，不把三表台账完成等同于完整财务报表已全部处理。

差额按来源单位与显示精度换算设定容差并说明。精确明细原则上精确核对，四舍五入差额另列记录；不用统一的大额阈值掩盖错录。由总计向分类及明细定位原因，可能有多项错误，逐项修正已证实原因后重算，禁止硬写总计或人为填“其他”补平。

## 7. 交付判定

交付输出副本和必要的来源映射/复核记录，说明主体口径、期间、单位、各年度取数来源及另列的重述差异、扩展科目、公式改动、重算工具和核对结果。

明确区分“报表录入完成”和“分析指标可计算”。非零项目未映射、关键合计不一致、关键 OCR 数字未确认或未执行重算时，标明具体工作表、期间和原因，不宣称全部通过。只缺可选补充资料时说明受影响指标，继续交付已完成报表。
