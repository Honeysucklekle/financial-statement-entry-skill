# 财务报表录入工作流

## 适用场景

用于以下类型任务：

- 同一目录下有 `PDF 审计报告` 和 `已设好格式的 Excel 模板`
- 需要录入 `资产负债表`、`利润表`、`现金流量表`
- 需要分别处理 `合并口径` 与 `本部/母公司口径`
- 只需填写 Excel 的输入列，不能破坏原格式、公式和汇总关系
- 需要在录入后自行复核，尽量发现错行、错列、跨年错填、追溯调整等问题

## 核心原则

1. 年份必须分开取数。
   Excel 中每个年份列，只能取自对应年份的审计报告。
   不要默认较晚年份报表里的期初数等于较早年份报表里的期末数，因为可能存在追溯调整。

2. 口径必须分开处理。
   `合并口径 Excel` 只对应合并报表页。
   `本部/母公司 Excel` 只对应母公司报表页。

3. 公式行不能硬写。
   先识别 Excel 中哪些行已有公式，像 `流动资产合计`、`净利润`、`现金及现金等价物净增加额` 等汇总行，一律保留公式，不直接覆盖。

4. 校验不能只看“有没有填进去”，还要看“勾稽是否成立”。
   如果录入后汇总值和原稿不一致，要往前追溯到具体明细行。

## 推荐执行顺序

### 1. 识别文件

先确认目录中的：

- 哪些是 `2023`、`2024` 审计报告
- 各年份审计报告分别是哪一份
- 哪个 Excel 是 `合并`
- 哪个 Excel 是 `本部/母公司`

如果文件名不规范，先通过工作表结构和报表标题确认，不要靠猜。

### 2. 识别 Excel 模板结构

至少确认以下内容：

- 需要填写的工作表名称
- 年份列位置，例如 `B/C/D` 分别对应哪一年，必须以模板表头为准
- 哪些行是公式行
- 是否有隐藏的校验行或差额行

重点检查以下工作表：

- `资产负债表`
- `利润表`
- `现金流量表`
- `补充资料表`

如果存在 `补充资料表`，要额外确认是否需要填写以下项目：

- `计提折旧额`
- `无形资产摊销额`
- `长期待摊费用摊销`

### 3. 从审计报告定位报表页

对每一份审计报告分别定位：

- 合并资产负债表
- 合并利润表
- 合并现金流量表
- 母公司资产负债表
- 母公司利润表
- 母公司现金流量表

如果 PDF 可抽文本，优先抽文本。
如果 PDF 是扫描件，先转图片/OCR，再人工复核关键数字。

### 4. 从审计报告附注定位补充资料

除三大报表外，还要检查审计报告附注后部是否披露以下项目：

- `计提折旧额`
- `无形资产摊销额`
- `长期待摊费用摊销`

如果 Excel 中存在 `补充资料表`，应把这三个数额录入对应年份列。

处理原则：

- 仍然按 Excel 表头年份分别取数
- 优先取自当年审计报告附注，不要跨年借用
- 如果原稿为空，则 Excel 对应单元格保持为空，不要强行填 `0`

### 5. 建立“来源 -> Excel 行”映射

不要边看边手填。
先建立映射，再统一写入。

映射时注意三类问题：

- 报表原稿有、Excel 没有：跳过或单独记录
- Excel 有、报表原稿为空：应保持为空，不要乱填 `0`
- 原稿同名项目在不同口径/年份位置不同：不能复用旧映射

### 6. 按口径、按年份写入

建议顺序：

1. 先录合并口径，再录本部/母公司口径
2. 每个口径内部，按 Excel 表头中的年份顺序依次录入
3. 三大报表录完后，如果存在 `补充资料表`，同步录入 `计提折旧额`、`无形资产摊销额`、`长期待摊费用摊销`
4. 每录完一个口径，先做一轮口径内校验，再进入下一个口径

写入时只改输入单元格，不改：

- 单元格格式
- 边框
- 列宽
- 公式
- 工作表结构

### 7. 做第一轮“单元格级复核”

抽查容易错的点：

- 同名科目是否写到错列
- 同名科目是否写到错口径
- 本该为空的格子是否误填了数字
- OCR 易错位的行是否串行
- `补充资料表` 中的 `计提折旧额`、`无形资产摊销额`、`长期待摊费用摊销` 是否填到正确年份列

高风险科目包括：

- `应付票据`
- `应交税费`
- `其他应付款`
- `资产处置收益`
- `汇率变动对现金及现金等价物的影响`
- `少数股东权益`

### 8. 做第二轮“勾稽校验”

这是最重要的一轮。

#### 资产负债表

至少核对以下汇总值与原稿是否一致：

- `流动资产合计`
- `非流动资产合计`
- `资产总计`
- `流动负债合计`
- `非流动负债合计`
- `负债合计`
- `归属于母公司所有者权益合计`
- `少数股东权益`
- `所有者权益合计`
- `负债和所有者权益总计`

如果 `资产总计` 或 `负债和所有者权益总计` 不一致，不要只改总计。
应从大类开始往下追：

- 先看 `流动资产/非流动资产`
- 再看 `流动负债/非流动负债`
- 再追到具体明细行

#### 利润表

至少核对：

- `营业利润`
- `利润总额`
- `净利润`
- `综合收益总额`

如果这些值不一致，优先往前检查：

- `营业收入`
- `营业成本`
- `期间费用`
- `其他收益`
- `投资收益`
- `公允价值变动收益`
- `信用减值损失`
- `资产处置收益`
- `营业外收入/支出`
- `所得税费用`

#### 现金流量表

至少核对：

- `经营活动现金流入小计`
- `经营活动现金流出小计`
- `经营活动产生的现金流量净额`
- `投资活动现金流入小计`
- `投资活动现金流出小计`
- `投资活动产生的现金流量净额`
- `筹资活动现金流入小计`
- `筹资活动现金流出小计`
- `筹资活动产生的现金流量净额`
- `现金及现金等价物净增加额`
- `期末现金及现金等价物余额`

如果 `期末现金及现金等价物余额` 不对，按以下顺序排查：

1. `经营/投资/筹资` 三大净额
2. `汇率变动对现金及现金等价物的影响`
3. `期初现金及现金等价物余额`
4. 再回到各活动明细

## 出错后如何追溯

推荐追溯法：

1. 先看最终汇总值是否和原稿一致
2. 如果不一致，看上一级分类汇总
3. 继续往前拆到更细一级
4. 找到第一次开始偏差的那一行
5. 只改这一行，再重新看汇总是否恢复

不要看到总计不对就大面积重录。

## 常见错误清单

### 1. 跨年错填

表现：

- 把较早年份的数据写进较晚年份列
- 把较晚年份报表里的 `期初余额` 当成上一年列
- 没先核对 Excel 表头年份，直接按惯性把某一列当成固定年份列

避免方法：

- 先读取 Excel 表头，确认 `B 列`、`C 列`、`D 列` 各自对应哪一年
- 按“Excel 该列表头年份 = 该年份审计报告”取数，不要按当前年份或习惯写死
- 如果是“三年一期”模板，也先看表头再录，不默认 `B` 列永远是某个固定年份

### 2. 口径串表

表现：

- 把母公司数字填进合并表
- 把合并数字填进本部表

避免方法：

- 每次录入前再次确认页面标题是否写着 `合并` 或 `母公司`

### 3. 把空白项误填为数字

表现：

- OCR 从相邻行串入
- 把本应空白的行误填成上一行或下一行数字

避免方法：

- 对原稿为空的单元格，默认保持空白
- 不要为了“表里都有数”而强行补值

### 4. 公式行被覆盖

表现：

- `合计`、`净额`、`总计` 不再自动联动

避免方法：

- 写入前先识别公式行
- 写入时跳过已有公式的单元格

### 5. 只校验脚本，不校验原稿

表现：

- 脚本内部自洽，但原稿来源本身就映射错了

避免方法：

- 必须做“原稿汇总值 vs Excel 计算结果”的勾稽校验

## 推荐输出方式

任务完成后，汇报内容至少包含：

- 已完成录入的文件
- 采用的年份口径规则
- 是否保留原模板格式和公式
- 做了哪些勾稽校验
- 是否发现并修正异常

## 可直接复用的任务提示词

以后做类似任务时，可以直接给出下面这段提示：

```text
请帮我把目录中的审计报告数据录入到已有 Excel 模板中。

要求：
1. 合并口径和本部口径分开处理。
2. 2023 列只能取 2023 年审计报告，2024 列只能取 2024 年审计报告，不要用期初数回填上一年，因为可能有追溯调整。
3. 只填写输入单元格，保留 Excel 原有格式、公式、边框、列宽和工作表结构。
4. 录入后必须做勾稽校验，不仅核对最终总额，也核对中间汇总。
5. 重点检查：
   - 资产负债表：流动资产合计、非流动资产合计、资产总计、流动负债合计、非流动负债合计、负债合计、权益合计。
   - 利润表：营业利润、利润总额、净利润、综合收益总额。
   - 现金流量表：经营/投资/筹资活动净额、现金及现金等价物净增加额、期末现金及现金等价物余额。
6. 如果汇总不一致，要往前追溯到具体明细行，不要只改总计。
7. 最后告诉我你改了什么、怎么校验的、是否发现异常。
```

## 本工作流最适合的执行方式

最稳妥的方式不是“人工边看边敲”，而是：

1. 先读取模板结构
2. 再定位 PDF 报表页
3. 建映射表
4. 自动写入输入单元格
5. 用 Excel 自身公式做勾稽校验
6. 对异常行人工回看原稿

如果时间紧，也至少要保留最后两步。
